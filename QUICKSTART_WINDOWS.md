# Journiv Windows - Quick Start Guide

## ⚡ Quick Start (5 Steps)

### 1️⃣ Download
- Go to [Releases](https://github.com/journiv/journiv-app/releases)
- Download `journiv-windows-*.zip`

### 2️⃣ Extract
- Right-click the ZIP file
- Click "Extract All..."
- Choose a folder (Desktop, Documents, etc.)

### 3️⃣ Run
- Open the extracted folder
- Double-click **`journiv.exe`** (or `journiv.bat`)

### 4️⃣ Wait
- First run takes 10-30 seconds to set up
- Console window shows progress
- Browser opens automatically

### 5️⃣ Journal!
- Create an account
- Start journaling immediately
- Your data is stored locally

## ✅ That's It!

No installation. No configuration. No Python. No Docker. Just double-click and journal.

## 📍 Where Is My Data?

Everything is stored in the folder where you extracted Journiv:
```
journiv-windows/
├── journiv.exe
├── journiv.bat
├── data/
│   ├── journiv.db          ← Your journal database
│   └── media/              ← Your images, videos, etc.
```

## 💾 How to Backup

Simply copy the `data` folder to another location:
- Copy → Paste
- That's your backup!

## 🆘 Troubleshooting

**Port Already In Use?**
- App automatically tries port 8001, 8002, etc.
- Check browser console for correct URL

**Can't Find Browser Window?**
- Check your taskbar
- Try Alt+Tab to switch windows
- Check if browser opened in background
